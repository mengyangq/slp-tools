What runs in your browser

SLP Tools is a set of static pages. Everything is computed on your own device; no transcript, file, or result is uploaded to any server. If a tool has any optional exception (such as downloading a language model on request), it is called out in that tool's credits below.

ChatLens — language sample analysis

Inspiration

ChatLens was inspired by QuidiVidi (Picardy Indexing), which aims to make CHAT/CLAN transcript analysis approachable for people newer to corpus methods or less comfortable with command-line tools. ChatLens shares that intention and takes a different route: a web app that runs in the browser rather than installed software. It is an independent implementation with no shared code; QuidiVidi is distributed under CC BY 4.0.

Sample data

The sample transcripts included with ChatLens (demo-play-session.cha, demo-plain.txt, demo-long-visit.cha) follow the TalkBank CHAT format and are synthetic examples created for teaching; they contain no real participant data.
