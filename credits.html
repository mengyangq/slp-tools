Inspiration

Prior work

QuidiVidi

ChatLens was inspired by QuidiVidi (Picardy Indexing), a free program for indexing and analyzing CHAT transcripts, and by how it makes language-sample measures approachable outside CLAN. Several ideas here follow its lead, including the "skip first / read a maximum of utterances" sampling options. QuidiVidi is distributed under CC BY 4.0; its source code is not published, and ChatLens is an independent implementation that shares no code with it — all counting logic here was written from the published CHAT/CLAN documentation.

What runs in your browser

SLP Tools is a set of static pages. Everything is computed on your own device; no transcript, file, or result is uploaded to any server. The one optional exception is the beta multilingual tagger in ChatLens, which downloads a language model to your browser from a public CDN when you choose to use it; even then, your transcript is tagged locally and never sent anywhere.
